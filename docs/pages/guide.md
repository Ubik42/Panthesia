# 使用说明

Panthesia 是钢琴练习程序：打开一首歌就能练。歌曲文件放在哪里都可以，Panthesia 不建曲库；曲库由 Keel 等文件管理工具负责。

## 打开歌曲

- 主页“打开乐曲…”，或把文件拖进窗口，或在资源管理器中双击（安装后关联文件类型）。
- 支持：MIDI（`.mid`、`.midi`、`.kar`）、MusicXML（`.musicxml`、`.mxl`、`.xml`）、ABC（`.abc`）、歌曲清单（`.panthesia`）。
- 主页右侧是最近打开的歌曲。
- 没有速度信息的 MIDI 按文件名里的 BPM（如 `BPM76`）播放。

## 歌曲设置

打开歌曲后先到歌曲设置：

- 选“观看与连续播放”，或左手、右手、双手练习，然后开始。
- “音轨”中可以设置每条音轨由谁演奏（你、自动、静音）、属于哪只手、音色和颜色。
- “更多 → 歌曲文件与版本”：同一首歌的其他版本、谱面、伴奏音频与人声等文件。程序会按文件名找出可能相关的文件，点“加入”即可登记。

## 演奏舞台

顶部工具条从左到右：返回、播放/暂停、上一小节/下一小节、速度（直接输入 BPM，或用 −/+ 每次 5 BPM），右侧是谱面、显示设置、节拍器、键盘缩放、音符标签（La）、书签、循环、手别、音量和菜单。

练习方式：

- **聆听**：连续播放，适合先听。
- **跟弹**：连续播放，你弹自己的那只手。
- **等待**：播放停在每个该你弹的音上，弹对才继续。

显示设置（齿轮）中可以选择：

- 只看瀑布、只看谱面，或谱面与瀑布同时显示（两者之间的分隔条可拖动）。
- 虚拟双手演示：歌曲没有指法时，程序为动画临时规划手别与指法，不改动你的标注。
- 和弦：不显示 / 级数 / 和弦名 / 两者。来源依次为你编辑过的和弦、乐谱中的和弦符号或数据集标注、自动分析；“编辑…”可以逐个修改，也可以采用自动分析的结果。
- 段落：前奏、段落 A/B 等标签；歌词：当前一行显示在键盘上方。

## 谱面

- 有 MusicXML 或 ABC 的歌曲直接显示谱面；只有 MIDI 时自动生成练习谱。
- “适合宽度”按谱面区的宽度重新排版，播放时自动跟随到当前一行。
- 转调、量化在“练习变体”中设置，谱面与演奏一起变化；原始演奏随时可以恢复。

## 伴奏与人声

在“歌曲文件与版本”中加入人声或伴奏音频（WAV、FLAC、MP3、Ogg）。打开歌曲时程序会把它们与演奏对齐。音量菜单里可以分别开关、调音量：

- 钢琴或伴奏轨默认关闭（与你弹的重复），人声默认开启。
- 在聆听和跟弹时随演奏播放；变速时音高不变。
- 对齐把握不大时会提示，可能是不同版本的录音。

## 自由演奏与录音

主页“自由演奏”。录音前可以设置速度（BPM）并打开节拍器；录音从按下“录音”的那一刻起算第一拍。停止后录音保存为“文档/Panthesia 录音/演奏 日期 时间.mid”，并立即作为歌曲打开，可以像其他歌曲一样练习，也可以用量化把节奏对齐到网格。

## 歌曲数据保存在哪里

- 你对一首歌做的修改（音轨与手别、指法、书签、和弦、登记的伴奏与版本）写在歌曲文件旁的同名 `.panthesia` 清单中，随歌曲一起移动和分享。只有第一次修改时才创建这个文件。
- 本机只保存属于你本人的数据：练习时长与历史、最近打开，以及可以重新计算的缓存。

## 设备

“设置”中选择输入键盘（MIDI 键盘或电脑键盘）、演奏音源（内置钢琴、`.sf2` 音色库、MIDI 输出设备或 VST3 插件）和扬声器，并可以试音。
