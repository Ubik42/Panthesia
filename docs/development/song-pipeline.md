# 歌曲资料链路：输入 → 自动 → AI → 输出

一首歌的全部资料按“从哪里来”分为四段。界面、清单与引擎都按这条链路判断一项资料是输入还是生成，与文件类型无关：同样是 MIDI，演奏者带来的是输入，从原曲转录出来的是生成。存储格式见 [panthesia-format.md](panthesia-format.md)，文件布局见其中“标准布局”。

## 1. 四段

| 段 | 谁来做 | 特点 | 结果存在哪里 |
| --- | --- | --- | --- |
| 输入 | 演奏者 | 不被程序修改；缺了可以补 | 歌曲文件夹中的文件，清单 `files[]` 无 `provenance` 或 `origin` 为 `human` / `imported` |
| 自动 | Panthesia 本地计算 | 确定、秒级、可随时重算 | 清单图层（`provenance.origin = "generated"`）或派生参数（`settings.variant`）；排版结果写文件 |
| AI | 外部模型（分离、转录、制谱、识谱）与智能检查 | 慢、在后台、结果有误差 | 歌曲文件夹中的文件，`provenance` 记录工具与来源；检查结果写回图层的 `review` |
| 输出 | 前三段的产物 | 长期保存、可被其他程序使用 | 歌曲文件夹中的文件或清单图层 |

## 2. 节点

### 输入

| 资料 | 角色 | 说明 |
| --- | --- | --- |
| 原曲音频 / 视频 | `source` | 分离与转录的起点 |
| 演奏 MIDI | `performance` | 演奏者自带的 MIDI（录制、下载、编曲） |
| 乐谱 | `score` | 自带的 MusicXML / ABC |
| 谱页 | `paper` | PDF 或图片谱 |
| 封面 | `cover` | 歌曲图片 |
| 自带分轨 | `stem` | 演奏者手里已有的伴奏、人声（如卡拉 OK 伴奏） |

### 自动（Panthesia 本地）

| 步骤 | 从 | 到 | 存储 |
| --- | --- | --- | --- |
| 分手 | 演奏 | `hands` 图层（逐音左右手） | 清单图层，草稿 |
| 指法 | 演奏 + 分手 | `fingering` 图层 | 清单图层，草稿 |
| 段落、和弦、调性 | 演奏 | `sections`、`chords`、`keys` | 清单图层，草稿 |
| 练习量化、转调 | 演奏 | 练习版本 | `settings.variant` 只存参数，打开时计算 |
| 排版五线谱 | 演奏 | MusicXML | 文件 `歌名.musicxml`（没有更好的谱面时） |
| ABC、乐谱导出 MIDI | 乐谱 | ABC / MIDI | 文件 |
| 练习 MIDI | 演奏 + 分手 + 练习版本 | 分手双轨 MIDI | 文件 `歌名（练习版）.mid`，按需生成 |

打开没有图层的歌曲时自动做分手、指法、段落、和弦和练习量化（`song_prepare`）。人工改过的图层（`human`）不被重算覆盖。

### AI

| 步骤 | 工具 | 从 | 到 |
| --- | --- | --- | --- |
| 分离 | BS-RoFormer-SW（music-transcription） | 原曲 | 钢琴、人声、伴奏（贝斯 + 鼓 + 吉他 + 其他之和） |
| 转录 | Transkun | 钢琴分轨（没有时原曲） | 演奏 MIDI |
| 制谱 | DuET | 演奏 MIDI | MusicXML、乐谱量化 MIDI |
| 识谱 | Audiveris（计划） | 谱页 | MusicXML |
| 检查 | AI 代理（计划） | 自动生成的草稿图层 | `review` 由 `pending` 改为检查者，必要时修改内容 |

**空分轨**：分离结果中平均电平比钢琴低 30 dB 以上（或低于 −60 dBFS）的音轨视为空，不写文件、不登记，在步骤记录的 `empty` 中注明。纯钢琴视频分离出的“伴奏”几乎是静音，不能当作伴奏；有人声的翻弹视频保留人声。

### 输出（长期保存）

| 文件 | 说明 |
| --- | --- |
| `歌名.mid` | 默认演奏；转录得到时为生成 |
| `歌名（乐谱量化）.mid` | 制谱得到的谱面 MIDI |
| `歌名（练习版）.mid` | 分手双轨（右手、左手、其他）、应用练习版本，给其他软件用 |
| `歌名.musicxml` | 谱面 |
| `歌名_钢琴.wav`、`歌名_人声.wav`、`歌名_伴奏.wav` | 分轨；钢琴分轨默认不随演奏播放（与乐器重复） |
| `歌名.jpg` | 封面（自带或取自视频画面） |
| 清单图层 | 分手、指法、段落、和弦、调性、练习段、书签 |

## 3. 来源记录

生成的文件在 `files[]` 中写 `provenance`：

```json
{ "origin": "generated", "tool": "music-transcription", "step": "transcribe", "from": ["source"], "createdAt": 1795505131000 }
```

- `step`：`separate`、`transcribe`、`engrave`（制谱 / 排版）、`omr`、`export`、`frame`（取视频画面）。
- `from`：来源文件的 `id`。界面据此画出“原视频 → 钢琴分轨 → 演奏 MIDI → 谱面”的来源。

每次运行 AI 步骤在 `extensions.panthesia.steps` 追加一条：

```json
{ "step": "separate", "tool": "BS-RoFormer-SW", "from": ["source"], "outputs": ["piano", "vocals"], "empty": ["accompaniment"], "createdAt": 1795505131000 }
```

`empty` 记下被判为空的分轨，界面显示“无（分离结果为静音）”，不再提示生成。

## 4. 界面

- 详情的资料分左右两栏：左栏“输入”列出 `origin` 不是 `generated` 的文件，缺少的输入可以补；右栏“生成”列出生成的文件与可执行的生成操作，每个文件注明来源步骤。图层（分手、指法…）在资料下方单独显示。
- 演奏界面顶栏有“音轨”面板：每条已登记的分轨一个开关和音量，在聆听与跟弹模式中随演奏播放。
- 声部面板中，逐音分了左右手的音轨显示“左 n · 右 n”，音符按手着色；整轨颜色只用于没有逐音分手的音轨。
