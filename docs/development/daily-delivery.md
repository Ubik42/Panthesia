## 明确边界

直接 MIDI 五线谱是简化读谱视图，完整多声部、连音线与专业排版继续使用 MusicXML 原谱。原曲变速图保持，BPM 调整控制实际播放速度；恒定 BPM 改写全曲不在本批范围。系统 MIDI 和外部硬件端口的音频设备、音量由 Windows 或外部设备控制。Pianoteq 独立程序需要明确的 MIDI 连接，本批直接接通的是 VST3 插件模式。
