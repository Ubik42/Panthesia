# 换肤、琴键与练习版本交付

日期：2026-11-18。本批在日常练琴版基础上增加外观和同曲练习变换。运行包入口：`outputs/releases/Panthesia-20261118-visual-variants/Panthesia.exe`。

| 用户要求 | 实现 |
| --- | --- |
| 更多特效 | 辉光、涟漪、流星三种落键样式；涟漪使用多重扩散光环，流星使用带方向的拖尾。沿用两种强度预设、三组光色、强度调节和减少动画 |
| 钢琴美化 | 暖象牙、白瓷、冰晶玻璃材质；琴身边框、压键反馈、红色毡条、黑键顶面反光与前沿刻面 |
| 换肤 | 练习室、午夜、玫瑰木三套内置皮肤，覆盖选曲、演奏页、舞台及相关控件；通过外观设置切换并保存 |
| 小节线透明度 | 小节、拍、细分三组独立滑杆，0–100；四分到三十二分的显示密度；清楚对拍、柔和、隐藏预设 |
| 转调 | 上下 24 半音、八度按钮、移到 C；调性来源可见且能修改；保留大小调性质 |
| 量化 | 原始、1/8、1/16、1/32；只对齐起音或同时量化时值；同音碰撞提示选择更细网格 |
| 同步 | 有效 MIDI 同时驱动瀑布、五线谱、发声、等待判断、定位和历史条件 |
| 原始资料 | 原 MIDI 不改写，现有原调/C调/人工量化文件全部保留；原谱关联保留，变换时使用 MIDI 五线谱 |
| 导出 | 原始与练习版 MIDI 分开；桌面端沿用成品缓存和另存流程 |

详细规范见 [同曲练习版本规范](practice-variants.md)。

## 使用入口

演奏页底部打开“转调与量化”。“外观与网格”打开皮肤、琴键材质、特效与网格设置。设置自动保存。

启用变换会暂停播放。请核对新调性和量化密度后点击播放。移调后仍按实体钢琴的实际目标音高演奏。

## 实际限制

本批检查使用引擎输入事件，没有代替用户按实体琴键。此批未重新做三条音源的输出回录，声音路由沿用日常练琴版已有实现和证据。量化不推断三连音或摇摆；没有加入用户自制皮肤文件加载和完整记谱编辑器。
