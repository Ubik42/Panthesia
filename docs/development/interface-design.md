# 界面规范

版本：2026-11-22。取代此前的“Synthesia 界面复刻规范”。用户 2026-11-22 说明：早期复刻 Synthesia 是开发初期交互与审美能力不足时的权宜做法；演奏之外的界面彻底重新设计，演奏舞台在保留上下布局的前提下优化。

## 1. 原则

- **一首歌是一组资料**。演奏 MIDI、五线谱、ABC、谱页、原曲、人声、伴奏，以及手别、指法、和弦、段落等图层，都在歌曲页上直接看到有没有、是什么、从哪里来；缺的资料就地给出生成或关联的操作。
- **练琴只差一步**。打开文件进入歌曲页，练习方式与开始按钮始终在同一位置；从 Keel 或资源管理器打开时不经过其他页面。
- **舞台只放练琴需要的东西**。任务、版本、诊断不进入演奏舞台；显示内容由“显示”设置开关。
- **同一份事实**。歌曲页、Keel 插件与 `probe` 使用引擎同一份歌曲汇总；同一个量在各处的写法相同（如调写作“Eb 小调”，时长写作“3:42”）。
- **安静的深色界面**。与舞台同一套深色表面，层次靠明度和细边框区分，强调色只用在主要操作和当前状态上。

## 2. 视觉语言

语义 token 定义在 `tokens.css`，组件只用语义 token：

| 类别 | token | 用途 |
| --- | --- | --- |
| 表面 | `--surface-base`、`--surface-panel`、`--surface-raised`、`--surface-hover` | 页面底色、面板、卡片与弹出层、悬停 |
| 文字 | `--text-primary`、`--text-secondary`、`--text-muted` | 标题与正文、说明、次要信息 |
| 线 | `--line-subtle`、`--line-strong` | 分隔、卡片边框 |
| 强调 | `--accent`、`--accent-strong`、`--accent-soft`、`--on-accent` | 主要按钮、选中态 |
| 状态 | `--state-ok`、`--state-warn`、`--state-missing`、`--state-generated` | 资料与图层的状态点 |
| 手 | `--hand-left`、`--hand-right` | 与瀑布的左右手颜色一致 |
| 形状 | `--radius-s`、`--radius-m`、`--radius-l`、`--space-1`…`--space-6` | 圆角与间距（4 px 网格） |
| 字体 | `--font-ui`、`--font-numeric` | 界面文字；数字用等宽数字 |

字号：页面标题 22 px、区块标题 13 px（字距略宽、次要文字色）、正文 14 px、说明 12 px。可点击区域不小于 32 px 高。动效 120–180 ms，遵守系统“减少动画”。

## 3. 启动页与歌曲页

### 3.1 启动页

- 左侧窄栏：品牌、`打开文件…`（主要按钮）、`自由演奏`、`设置`。
- 右侧：最近打开的歌曲列表。每行：标题、所在文件夹、资料标记（MIDI、谱、音频、人声）、时长与调、上次打开时间。文件不存在的行变暗并标“文件不存在”；右键“从列表移除”。
- 空列表时说明可以打开的文件类型，以及可以从资源管理器或 Keel 双击打开。

### 3.2 歌曲页

宽屏为两栏，窄屏（< 960 px）右栏移到上方。

```
┌ ← 返回   标题 / 艺术家                                              ⋯ ┐
├───────────────────────────────────────────────┬───────────────────────┤
│ 钢琴卷帘预览                                    │ 练习                   │
│ 3:42 · 97 BPM · 4/4 · Eb 小调 · C2–C6 · 2 轨     │ [连续播放 | 等待按键]  │
│                                                │ [左手 | 右手 | 双手]   │
│ 资料                                            │ [ 开始 ▶ ]             │
│ ┌演奏 MIDI ────────┐ ┌五线谱 MusicXML ─────┐    │                       │
│ │ 文件名 · 2 个版本 │ │ 没有 · [从 MIDI 生成]│    │ 声部、手别与乐器  ›    │
│ └──────────────────┘ └─────────────────────┘    │ 转调与量化        ›    │
│ ┌ABC 谱┐ ┌谱页 PDF┐ ┌原曲┐ ┌人声┐ ┌伴奏┐        │ 谱面              ›    │
│                                                │                       │
│ 图层                                            │                       │
│ 手别 人工 · 指法 — · 和弦 生成 · 段落 导入 …     │                       │
└───────────────────────────────────────────────┴───────────────────────┘
```

**资料卡片**（七类，顺序固定：演奏 MIDI、五线谱、ABC 谱、谱页、原曲、人声、伴奏）：

- 状态点：有（文件名，来源为生成时标“生成”）、缺失（清单引用但找不到）、没有。
- 旁边发现但未登记的文件（命名规则识别）显示为“发现 x.wav”，一键登记。
- 操作：有 → 在资源管理器中显示、移除登记、切换版本（演奏有多个时）；没有 → 生成（可用时）、关联文件…。
- 生成：五线谱与 ABC 由引擎从当前演奏生成；演奏 MIDI 由原曲转录、人声与伴奏由原曲分离，使用外部工具，在后台任务中运行，卡片上显示进度；工具未配置时按钮旁说明“需要在设置中指定转录工具”。

**图层**：手别、指法、和弦、调性、段落、歌词、速度。每项一个标签：名称 + 来源（人工 / 导入 / 生成）或“—”。点击打开对应编辑器；没有的图层给出“分析”（和弦、调性、段落、手别、指法）。

**练习栏**：模式与手为分段按钮，选择会记住；“开始”在两种模式间共用。下方是进入二级页面的入口（声部与乐器、转调与量化、谱面）。

## 4. 演奏舞台

上下顺序保持：顶部工具条 → 时间线 → 谱面（可关）→ 瀑布 → 琴键。

### 4.1 瀑布上的标注

- 小节线上的文字放在**右侧**，紧贴右边缘，右对齐，不遮挡音符密集的中部。
- **段落**：段落开始的小节线右侧显示段落名胶囊（如“副歌”）。
- **小节编号**：歌曲有段落图层时，按段内序号编号：每个段落的第一小节为 1，依次 2、3、4……；没有段落时用全曲小节号。
- **拍号**：默认不显示。显示设置中“显示拍号”开启后，只在拍号出现与变化的小节标注。
- 时间线上方的读数同样使用段内编号：“副歌 · 3 小节 · 第 2 拍”。

### 4.2 五线谱

- 一次显示一行（一个系统），高度按一行谱适配，不出现内部滚动条；播放跨行时整行切换，下一行预先排好。
- 手动查看其他位置时用工具条上的前后翻行，或在谱面上滚轮翻行；不使用内嵌的滚动区域。

### 4.3 工具条与设置

- 工具条使用舞台同色的深色半透明表面，图标按钮 36 px，分组之间用间隔而不是竖线。
- 弹出设置统一为一种面板：标题、分组（区块标题 + 行），每行左侧名称、右侧控件；开关、分段按钮、滑块的尺寸一致；面板最大高度不超过舞台高度的 80%，超出时整体滚动，面板内部不再嵌套滚动区域。

## 5. 后台能力的入口

| 能力 | 入口 | 界面只显示 |
| --- | --- | --- |
| MusicXML / ABC 生成 | 歌曲页资料卡片 | 生成中、完成后的文件 |
| 转录、分离（外部工具） | 歌曲页资料卡片；工具位置在设置 → 外部工具 | 进度、结果文件；日志在设置中 |
| 和弦、调性、段落、手别、指法分析 | 歌曲页图层 | 生成的图层，可编辑、采用 |
| 转调与量化 | 歌曲页 → 转调与量化 | 当前练习版本 |
| 诊断与日志 | 设置 | 一次操作的结果 |
