# 长期任务执行约定

更新：2026-11-19。当前 Goal active。任务完整范围以 current-goal.md、modernization-roadmap.md 与实际 active Goal 为准；本文件只规定执行方式，不另设一套开发目标。

以歌曲管理、演奏和 DuET 制谱闭环为主线，按收益处理 Synthesia 官方功能矩阵。元数据、复杂分组与交换细节仅在阻塞主流程时提前处理。

允许替换旧实现、合并重复模块、重写界面和存储适配。被替代的生产路径应退出，兼容层必须有用途和退出条件。数据保护针对用户 MIDI、谱面、设置和练习历史：源文件归属明确，迁移可恢复，检查使用隔离资料。原有代码、交互和错误行为可直接改造。

每轮集中完成一批实际改造，按用户流程组织接口与状态，音频实时路径与生成、存储、界面工作分离。拆文件、文档和模型声明均不能代替产品行为。

每批只做受影响编译与必要关键行为 / 小范围界面检查，复用已通过证据。里程碑制作对应当前源码的运行包，确认资源和独立启动。不得用正式用户资料作检查样本。

每轮更新路线图、架构关系与续接记录；涉及官方能力时同步功能矩阵的具体行。准确区分源码改造、已验证行为、运行包与整体完成。剩余项按原目标记录，设备、平台和服务依赖仍需具体适配及验收。

恢复时从当前工作区与 modernization-handoff.md 续接。遇到运行中的进程，继续观察同一进程；不能因观察超时而重启。用户明确暂停时停止工作。未经要求不推送远端。
