# Panthesia 主线收束计划

更新：2026-11-19。按用户最新决定执行；原长期 Goal 已清除。

## 产品范围

用户选一首歌，选择演奏和谱面版本，连接音源，按需要调整 BPM、转调或量化，直接播放、跟弹、逐步练习和循环。主线围绕这条流程组织。

| 范围 | 主线处理 |
| --- | --- |
| 歌曲管理 | 文件夹树、搜索、最近打开、收藏 / 队列、演奏与谱面版本 |
| 演奏 | 连续播放、按键引导、BPM、声部与音轨、定位、A/B 循环及循环次数 |
| 谱面 | MIDI 简化谱、MusicXML、谱页，DuET 生成 / 预览 / 采用；与演奏版本和练习变换共用身份 |
| 声音与外观 | 内置音源、Windows MIDI、Pianoteq，音量、键盘、瀑布、网格、皮肤和特效 |
| 资料保护 | 原始文件归属明确；设置和旧历史继续读取、备份；既有成绩不删除、不冒充新练习数据 |

## 独立实验分支

feature/assessment-lab（ca4aeb5）保留音符时序判定、错漏音、准确率、表现要求、评分历史 / 回放、达标日课、速度晋级和评估上下文重构。主线不提供启用设置。以后只有明确重新授权，才考虑从该分支选择内容。

主线实时输入已改用 Guidance 跟踪所需琴键；连续播放不提交判定事件。循环结束直接续播，不创建成绩任务、等待成绩汇总或回放编码。删除主线 round_save 模块、内部发布消息、专用分析队列和退出时成绩保存步骤。历史读取和备份所需的数据类型保留兼容。

本次以后先依据真实使用问题修复主流程，新增功能另行明确范围。元数据扩展、复杂目标体系和按功能矩阵无限推进的安排退出当前主线计划。

## 已知边界

DuET 仍依赖本机已配置的 Python 与模型。复杂大曲的整曲谱面有容量限制，超限时可使用瀑布；偶发帧间隔问题仍需按具体曲目定位。本次不将这些既有边界写成已经解决。最新源码、运行包和检查证据见 modernization-handoff.md。
