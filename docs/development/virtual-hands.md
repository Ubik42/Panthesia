# 虚拟双手

状态：待开始（计划阶段 R8）。用户决定自行实现。

## 目标

演奏舞台上可开关的俯视二维手部动画，从歌曲已保存的手别、指法与播放时间驱动。覆盖穿指、持音换指、双手交叉。参考视频 BV1gasF6UERM：白色细长手型、11 度跨度、完整 88 键视图。手部不修改原始音符、播放速度、音源或等待判定；缺少指法的音符不编造标注。

入口：演奏页"显示"菜单的"虚拟双手演示"复选项，默认关闭；外观设置调不透明度。

## 现有代码

提交 6ccf32d、9561452 是用户已否定的简化原型：`features/practice/virtualHand*.ts`（Worker 规划、姿态采样、Canvas 2D 绘制）。R8 会用新实现替换这些代码。

用户决定（2026-11-21）：只参考公开的思路与视频观感，自行实现同等质量的版本。

实现方向：每只手为带关节长度约束的骨架；按指法目标做两段 IK；掌部位置由当前与下一组目标平滑插值；穿指与交叉按手部高度排序；皮肤用 SDF 或贝塞尔轮廓渲染在舞台 WebGL 图层。手别分离与指法缺失时，可先调用分析服务（R6）生成 `generated` 图层。
