# 虚拟双手

状态：受阻（计划阶段 R6）。

## 目标

演奏舞台上可开关的俯视二维手部动画，从歌曲已保存的手别、指法与播放时间驱动。覆盖穿指、持音换指、双手交叉。参考视频 BV1gasF6UERM：白色细长手型、11 度跨度、完整 88 键视图。手部不修改原始音符、播放速度、音源或等待判定；缺少指法的音符不编造标注。

入口：演奏页"显示"菜单的"虚拟双手演示"复选项，默认关闭；外观设置调不透明度。

## 现有代码

提交 6ccf32d、9561452 是用户已否定的简化原型：`features/practice/virtualHand*.ts`（Worker 规划、姿态采样、Canvas 2D 绘制）。R6 会用新实现替换这些代码。

## 授权问题

参考实现 [V9011N/pygame-piano-animator](https://github.com/V9011N/pygame-piano-animator)（提交 ae8ae035c76ef9591926892cdbf603371be73499，本地副本 `work/hand-animation-research/`）没有许可证文件。默认著作权下，复制或移植其源码、参数表、权重（`hands.py`、`skins.py`、`learned_weights.json` 等）进入本 GPL 仓库不合法，"注明来源"不能替代授权。

可选路线：

1. 联系作者取得许可（MIT 或 GPL 兼容），然后移植其关节求解与动作轨迹。
2. 只参考公开的思路与视频观感，独立实现：每只手为带关节长度约束的骨架，按指法目标做两段 IK，掌部位置由当前与下一组目标平滑插值，穿指/交叉按手部高度排序。皮肤用 SDF 或贝塞尔轮廓渲染在舞台 WebGL 图层。
3. 暂停 R6。

需要用户决定。
