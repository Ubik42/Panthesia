# 虚拟双手演示

本批由用户追加，覆盖可开关演示、穿指、持音换指和双手交叉。用户否定三维手套试验后，产品改用 pygame-piano-animator 的俯视二维卡通方向。该仓库当前没有项目许可证，本实现未复制其源码、权重或素材。

## 入口与数据

演奏页 → 显示设置 → 虚拟双手演示。外观设置可调整不透明度。默认关闭，开启时增加键盘展示区域。缺少逐音指法的音符跳过演示，歌曲设置中补充后生效。

唯一数据来源为 LoadedSong 中的手别、指法、源时间音符和在当前速度下有效的 fingerActions。持音换指把接触时间分为前后两个手指；穿指由相邻的已标注指法过渡驱动。手部不修改原始音符、标注、播放速度、音源或等待判定。

## 实现分工

- virtualHandPlan：只读接触计划，按手、手指建立区间；失效或其他速度的换指动作不采用。
- virtualHands.worker：后台准备计划，完成即释放；切歌、关闭或重新准备取消旧任务。
- virtualHandPose：从播放时钟采样姿态，包含预备、触键、抬指、穿指和交叉抬腕；任意定位可重复采样，不依赖上一次绘制状态。
- virtualHandDrawing：Canvas 俯视皮肤。掌指使用统一轮廓，绘制指甲、关节细线、衣袖和柔和阴影；重叠按手部高度排序。不增加 WebGL 上下文与 Three.js 依赖。画布像素预算限制为四百万。
- virtualHands：只负责生命周期和绘制协调；时钟仍由原播放模块维护。

这是一组按已有指法生成的演示姿态。复杂不合理指法、同指同时按多个相距很远的键，仍需要用户修正标注；本批未实现参考仓全部人体约束、刮奏和个性化手型编辑。

## 交付核对

定向核对真实桌面中的开关、暂停/定位、换指、穿指、交叉及无脚本错误；运行包与源码分别登记。此前试验图和被用户否定的方案不作为最终视觉验收。完整工程 B05–B07 仍按 current-plan.md 推进。
