# 日常可用标准与界面重整

日期：2026-11-18。依据本轮用户实用反馈、当前源码、本机设备与 Synthesia 官方流程说明。本文是修订后的实施依据，本轮只调查、明确行为并更新计划。

## 当前结论

`Panthesia-20261118-basic-ux` 保留为问题复现版本。用户报告演奏无声、退出双框；这些问题尚未修复。现有编译、启动、文件摘要和保存恢复记录不能证明实际练琴可用。当前版本未达到日常可用标准。

本批以正常使用的完整流程作为范围：启动、选曲、确认发声、演奏、调整、返回选曲、退出与下次继续。先完成这些流程，再评价整体交付。

## 使用流程

### 曲库页：选择要练的内容

启动默认进入曲库页。顶部提供继续上次曲目，保留最近位置；用户主动继续后进入演奏。左侧展示实际扫描根目录及其子目录树，支持展开、折叠、选中文件夹和键盘导航。中间只显示该目录的曲目，搜索可明确选择当前目录或全部曲库。目录树记住展开和选择，曲目列表记住滚动位置。

右侧显示选中曲目的标题、版本、原速 BPM、时长、声部和谱面预览，提供试听与开始演奏。同曲不同文件的版本后缀应可辨认，避免长标题截断后全部看起来相同。选中、试听、进入演奏分别是明确动作。扫描已有曲目时保持可浏览，目录丢失显示未连接；移除登记保留原文件。

### 演奏页：集中弹琴

谱面或瀑布占主要区域，选曲列表退出主画面。顶部提供返回曲库、曲名与当前视图。高频操作始终可见：播放/暂停、等待弹奏/连续、BPM、左右手、小节循环、音量和音源入口。后台记录、资料关系与高级编辑按需打开。

底部显示两种位置：`第 12 小节 · 第 3 拍` 和 `曲目时间 01:23 / 06:22`。连续时间轴按实际曲目时间排列，叠加小节标记，允许拖到小节内部；小节与时间共用一次定位命令。实际练习用时独立标注，等音等待时曲目位置停止、练习用时继续，暂停时练习用时停止。

速度主控以 BPM 显示、输入和步进，提供恢复原速。引擎已有播放倍率可继续作为内部实现：用户给定目标 BPM，按当前位置或选段的原曲基准换算；保留原曲速度变化图，显示乘入倍率后的实际 BPM。变速曲目清楚标注跟随原曲变化，避免把原曲 BPM 当作实际演奏 BPM。恒定 BPM 重写整曲不纳入本批。

从演奏页返回曲库时暂停、止音、保存当前进度；返回演奏恢复同一曲目与位置。页面切换保留播放引擎和声音连接，不因界面组件卸载而释放音源。等待/连续切换不重置位置或要求重新播放。

### 设备与声音页：选择并确认发声

提供清楚的三段链路：`MIDI 键盘输入 → 演奏音源 → 发声设备`。

- 输入：列出实际 MIDI 键盘，按键时显示音符和输入活动。
- 音源：明确列出 Windows 系统 MIDI 音源、Pianoteq 6 VST3、内置 SF2 和其他已发现输出。显示当前选择、连接失败原因、重连与测试音。
- 发声设备：内置和支持设备选择的插件路由可选择扬声器/耳机。Windows 系统 MIDI 的输出遵循其系统路由，界面应说明由 Windows 控制的部分，避免显示无效选择。

Pianoteq 插件模式由本软件托管并直接接收 MIDI；独立程序模式需要实际可用的 MIDI 连接，不能把发现一个 exe 当作已建立发声链路。插件窗口用于音色调整；可正常试音后再保存该音源为下次默认。音源失败时明确显示，用户可主动改选备用音源。

测试音必须走当前实际路由。状态应区分收到键盘事件、音源处理、音频输出；可获取音频的路由显示电平。外部 MIDI 无法观察音频时如实标明。连接成功或测试音命令被接收，均不能单独标为可听见。

### 退出与恢复：一次操作完成

演奏中关闭：止音、结束本次练习、保存进度和设置、释放输入与声音设备、关闭窗口。正常保存期间只在需要时显示短暂状态，保存成功自动退出。没有产生演奏记录也允许退出。

确实存在无法保存的内容时，只显示一次应用内决定：重试、返回、放弃本次未保存内容并退出。保留已有事务、恢复资料和原文件保护。桌面退出统一由原生关闭协调器负责，浏览器版本的 beforeunload 只承担浏览器离开保护；取消重复的原生警告与页面提示。

## 实现责任

- 应用壳负责曲库、演奏、设置和回顾页面，以及导航和统一关闭交互。
- 曲库模型负责扫描根目录、目录树、曲目身份、文件可用性；前端不重新扫描整个硬盘。
- 播放引擎负责谱面位置、曲目时间、拍位、BPM、等待方式与循环，发布同一份状态给谱面、瀑布和时间线。
- 声音层分别表示键盘输入、音源和音频设备。路由有明确生命周期、错误和重连操作，播放与页面切换复用同一连接。
- 保存层继续负责后台写入与恢复，普通浏览和练琴不要求反复确认保存。

复用现有引擎、文件观察、曲库资料、存储和插件适配，只调整上述责任边界及缺失行为。本批不启动框架迁移、专业评分重写、完整记谱编辑或新的后台任务体系。
