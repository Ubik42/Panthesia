Panthesia · 钢琴练习室

启动与资料
双击 Panthesia.exe 或 Open.cmd，移动软件时复制整个运行包，并保留 default.sf2。
界面、音乐引擎和 Verovio 乐谱排版已包含在程序中。Windows 需要 Microsoft Edge WebView2。
“帮助 → 关于 Panthesia”显示当前构建、程序位置和实际资料目录。
升级时可把新运行包放在新目录，再连接原资料。已有 MIDI、谱面、练习记录和个人设置继续放在原位置。
软件优先使用 Panthesia 资料位置；尚无新资料时可沿用既有资料位置。显式指定的资料目录优先。
使用练习资料备份迁移记录；MIDI 和外部谱面原件也应另行保存。移除曲库登记与删除源文件是不同操作。

开始练琴
1. 从曲库左侧文件夹树选择目录。已有扫描目录直接列出；新增目录后等待后台发现曲目。
2. 选择歌曲，查看其演奏版本与文件位置，再点击“开始演奏”。同内容的多个位置归在同一演奏版本中。
3. 演奏页上方选择演奏版本和练习谱面。“添加 / 管理谱面”用于关联 MusicXML/MXL、查看初稿和使用 DuET 制谱。
4. 底栏选择“弹对后继续”或“连续播放”。连续播放会自动发声，允许跟弹；弹对后继续会在目标声部等待实际按键。
5. 直接输入 BPM 改变速度，点击“原速”恢复。原曲有速度变化时，软件继续使用原速度图。
6. 从左上角返回曲库会暂停并保留当前位置。空格开始 / 暂停，“停止发声”用于立即止音。

专注演奏
在视图工具栏点击“专注演奏”，收起菜单和版本设置，为谱面与瀑布留出更多空间。
右上角“版本与设置”仍可选择演奏 / 谱面、调整转调量化、手别、外观和音源。Esc 或面板右上角可收起设置。
BPM、播放模式、定位和 A/B 循环一直在主画面。右上角状态点提示音源连接情况。
点击“退出专注”恢复普通布局；也可返回曲库选曲。专注布局会自动保存，并参与布局方案和界面备份。

键盘与音源
打开演奏底栏的音源入口或“设置 → 键盘与音源”。
选择 MIDI 输入键盘，再选择内置钢琴、Windows 系统 MIDI 或 VST3 乐器。
Windows 系统音源为 Microsoft GS Wavetable Synth；外部 MIDI 输出需要连接能实际发声的设备。
Pianoteq 6 使用其 VST3 插件；在设置中选择插件文件与扬声器 / 耳机，可打开插件窗口调整音色。
内置钢琴和 VST3 的输出设备可单独选择。点击“播放测试和弦”，结合输入活动和输出电平检查连接。
音源入口会显示连接中、已连接或错误。切换曲目与模式后仍可从同一入口检查当前音源。

三类谱面
MIDI 简化谱：未关联 MusicXML 时直接生成临时双谱表，书面节奏按十六分音符整理。发声、定位、跟随和选段使用原演奏时序。
量化练习谱：启用练习量化后，按当前有效演奏重新记谱。它与原始 MIDI、正式谱面分别管理。
所选原谱：关联或采用的 MusicXML/MXL。启用量化时，可在谱面工具栏选择量化练习谱或所选原谱。
这些谱面共用 Verovio 排版、逐音跟随、缩放、指法和选段操作。再次打开相同内容可复用本次启动内的排版缓存。
简化谱按音区分上下谱表，复杂三连音、摇摆和声部整理建议使用 DuET 或正式谱面。简化显示不会启用演奏量化。

转调与量化
演奏底栏打开“转调与量化”。可上下 24 半音、按八度调整或移到 C；量化可选 1/8、1/16、1/32。
起点量化与时值量化分别控制。变换作为当前演奏版本的练习条件记住，原始 MIDI 不改写。
两个连续同音量化到同一格时，请选择更细网格。复杂节奏可恢复原始时序，继续使用简化谱或关联原谱。
文件菜单分别提供原始 MIDI 和练习版 MIDI 导出。正式记谱文件与临时练习谱具有不同用途。

定位与循环
时间线同时显示曲目时间、小节和拍位，支持拖到小节内部。
点击 A / B 设置当前位置为范围端点，再启用“循环选段”。
也可打开“选音符”，在谱面或瀑布中点选首尾两个音符；允许选到一半切换视图。范围包含所选音符的完整时值。
正在循环时显示局部精细时间线和全曲范围概览。退出循环保留当前位置及正在播放 / 暂停的状态。
“小节与分段”提供按小节细调和已保存练习段。原谱的反复与跳转按实际演奏经过区分。
切换歌曲或练习条件后，旧的临时选段草稿会清理。

DuET 制谱
从“添加 / 管理谱面”选择 DuET，生成任务使用当前歌曲的原始 MIDI。
生成完成后查看初稿、演奏顺序与对应结果，再采用为谱面版本；之后可从演奏页重新选择。
“演奏与制谱设置 → DuET 制谱”可填写 Python、模型路径与计算设备，并检查环境。保存前会备份原配置。
本机需要已安装 DuET、Torch 和模型权重；运行包没有包含这些大型依赖，也不会在制谱时自动下载。
本机已有共享环境可自动发现；迁到另一台机器后需在该页配置。环境变量会优先于文件配置生效。
MusicXML 是主要交换格式。MuseScore 用于后续编辑和排版，Verovio 用于软件内显示。

外观与按键
演奏页“外观与网格”进入独立外观页：练习室 / 午夜 / 玫瑰木皮肤，暖象牙 / 白瓷 / 冰晶玻璃琴键，辉光 / 涟漪 / 流星落键。
“演示落键”使用演奏页同一绘制器，只演示画面。减少动画选项同时遵循系统设置。
小节线、拍线和细分线透明度分别调整，数值越高越清楚，0 为隐藏。“清楚对拍”可快速设置十六分网格。
音符显示、练习室布局、电脑按键和操作快捷键分别设置；调整立即生效并自动保存。外观默认值只恢复外观参数。

练习记录与关闭
完成练习后可查看错音、漏音、节奏与历史，记录按实际练习条件区分。
录制演奏记录实际 MIDI 输入，可回放或导出；计划、队列和练习资料备份从对应管理入口打开。
关闭软件会止音并保存。如有尚未完成的保存，窗口内提供重试、返回或退出选择。
