# 演奏舞台渲染：瀑布、光效与虚拟双手

## 图层与分工

自下而上：背景与键盘光晕 → 琴键列线、拍线与小节线、循环接缝 → 音符块 → 标签文字 → 光效 → 琴键 → 虚拟双手 → 文字叠层（和弦、歌词、段落、小节号）。

| 部分 | 实现 | 位置 |
| --- | --- | --- |
| 瀑布（背景、网格线、音符） | WebGL2 实例化，一次绘制；没有 WebGL2 或上下文丢失时由同一接口画到 Canvas 2D | `features/practice/waterfallLayer.ts` |
| 音符标签 | Canvas 2D，按内容缓存 | `waterfallLabels.ts` |
| 琴键 | Canvas 2D；底图按尺寸与标签缓存，每帧只重画按下的键 | `stage/Piano.tsx` |
| 光效 | WebGL2 实例化（光晕、光束、涟漪、星屑） | `PianoEffects`、`midiVisualizerShaders.ts` |
| 虚拟双手 | Worker 规划动作，Canvas 2D 绘制 | `virtualHand*.ts`、`virtualHands.worker.ts` |
| 时钟 | 引擎状态帧之间按播放速度插值 | `waterfallClock.ts` |
| 颜色 | 舞台颜色集中在一处，按皮肤与光效配色 | `stageTheme.ts` |

**性能**：19,200 音符、2560×1440、DPR 2、CPU 降速 4 倍时，绘制 p50 1.2 ms、p99 3.9 ms（原 Canvas 2D 为 p99 9.9–17.4 ms）。显示表面最多 4,000,000 像素，DPR 最多 2。

## 光效

- 光晕的内外半径 smoothstep、预乘透明度，以及粒子的 1−t² 衰减改编自 [MIDIVisualizer](https://github.com/kosua20/MIDIVisualizer)（MIT，提交 `1c942137`）。上游的窗口、渲染器、贴图与音频没有接入。
- 每批最多 2,048 个图元；粒子最多 1,536 个（回退时 420 个）。
- 引擎状态中的 `pressedKeys` 带击键序号，前端据此区分同音重弹；CC64 读取踏板状态。
- 暂停、定位、循环回跳、切歌、失焦与关闭特效时清除旧的视觉状态；系统要求减少动画时只保留短暂光晕。光效不参与等待判定与发声。

## 虚拟双手

- 演奏页“显示”菜单中的开关，默认关闭；外观设置调不透明度。俯视二维卡通手型，覆盖在琴键上，不拦截操作。
- 每只手是带关节长度约束的骨架，按指法目标做两段 IK；掌部位置在当前与下一组目标间平滑插值；穿指与交叉按手的高度排序。
- 数据：已保存的手别与指法。歌曲缺少时调用 `PlanVirtualFingers` 只为动画规划（不写回歌曲）：没有手别的音轨按小节分块交给束搜索分手，规划不了的地方按两手平均音高的中点划分；指法规划以已保存的指法为锚点，规划失败时按音在和弦中的位置分配。
- 按下超过 0.6 拍的旧音只对手腕施加很弱的牵引；手指目标偏离手型超过 3 个键宽时视为已松开（由踏板延音）。
- 自行实现，不使用 pygame-piano-animator 的代码、参数与权重（见 [sources-and-licences.md](sources-and-licences.md)）。
