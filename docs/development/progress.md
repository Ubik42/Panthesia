## 2026-11-24 · 拇指改为关节空间 IK（生理限位、舒适姿态、连续性）；179 mm 手的尺寸常数；手指 DIP 联动按实测

- 拇指：原来在离散网格中选掌骨角度，再用“关节总向上拱”的两段骨求解，造成两类问题：相邻帧在两个局部最优之间跳；指尖近而低时 MCP 被迫后翻。改为四个关节角（CMC 张开、下倾，MCP、IP）的正向运动学，在生理限位内用阻尼最小二乘求解：指尖到目标、与舒适姿态的距离（CMC 范围宽、IP 窄，对应拇指主要靠 CMC 与 MCP 击键）、与上一帧的变化，三者加权；以上一帧热启动，热启动够不到时再试多组起点。MCP 与 IP 在同一屈曲平面，平面朝手指方向转 35°。按键时指尖权重 ×12；排序后拇指精确落到排好的位置。拇指的键超出其张开范围时手向外移。
- 手指：DIP 对 PIP 的联动改为 0.77 / 0.75 / 0.75 / 0.57。

## 2026-11-24 · 手部 benchmark；手腕改为最小急动度路径；拇指连续求解；手缩小到 0.94

- benchmark：`panthesia-web/scripts/hand-bench.mjs`（替代 `hand-check.mjs`），说明与当前结果见 [hand-benchmark.md](hand-benchmark.md)。6 首转录曲各 90 秒、60 帧/秒，统计击键命中、保持覆盖、交叉、拇指反折、上翘、蜷缩、手腕速度 / 加速度 / 急动度 / 突变、手掌转速、指尖与关节角速度 / 角加速度 / 突变、每帧耗时；`--baseline <提交>` 逐项对比。
- 整手跳变的原因：手腕放置按各键拉力的总和归一，没有键按住时极小的拉力也能把手整体拉过去，手先冲出再折回，手腕弧线跟着上下弹。改为加权最小急动度路径（三阶差分惩罚的带状最小二乘，Flash & Hogan）：键拉得紧处贴合，拉得松处保持平滑；再在平滑路径上逐帧检查可达，把需要的修正同样平滑后叠加；相邻 4 秒块在边界前后 0.8 秒内混合。手腕突变 7.0 → 3.0 ‰，急动度 36 → 11 m/s³，加速度 p99 16.4 → 8.0 m/s²，保持覆盖 90.9 → 92.3 %。
- 拇指：掌骨转角与下倾改为细网格搜索并惩罚与上一帧的偏离（状态存在 `HandMemory.thumb`），关节突变 29.5 → 20.5 ‰（主要来自拇指在两个局部最优间跳）。限制掌骨转速会让拇指停在反折姿态，未采用。
- 手的大小：模型手长约 190 mm（大号男性手），整体缩到 0.94（约 179 mm，成人平均），骨架与网格同比例。缩到 0.9 时击键命中降到 93.8 %，原因是指法的跨度表仍按全尺寸的手；下一步让指法跨度随手的大小变化后再缩小。
- 代价：拇指反折 23 → 32 ‰、按键手指蜷缩 35 → 58 ‰（约三分之二来自缩小），每帧耗时 0.04 → 0.16 ms。
- 检查：`cargo check`、`npm run build`、benchmark 对比 09af3e8。
