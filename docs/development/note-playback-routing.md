# 逐音播放规则

更新：2026-11-19。对应 C02、C07、C12、C13。手别与播放职责独立保存。

## 行为

| 规则 | 等音与评分 | 声音 | 显示 |
| --- | --- | --- | --- |
| Human，需要弹奏 | 参与当前选手的练习 | 聆听 / 连续模式播放示范，其余练习模式等待用户 | 显示 |
| Auto，自动伴奏 | 不作为练习目标 | 各模式均自动播放 | 显示 |
| Mute，忽略 | 不作为练习目标 | 各模式均不播放 | 瀑布与 MIDI 练习谱隐藏；外部原谱保留原文 |
| 沿用音轨 | 由音轨与当前手别决定 | 由音轨与模式决定 | 保持原行为 |

音轨静音优先。音轨设为自动伴奏时，Human 音符也转为伴奏，逐音 Mute 继续生效。整轨隐藏与静音仍是独立设置。规则按曲目内容身份及稳定的 track / note_index 保存；转调和量化保持音符索引。

[官方 Hand Parts](https://github.com/Synthesia-LLC/metadata-editor/wiki/Hand-Parts) 说明 L / R 为手别，B 为背景，X 为丢弃。导入时 L / R 写入 Human 与对应手别，B 写入 Auto，X 写入 Mute。原 NoteOn 序号先映射至本地稳定索引。默认保留已有个人手别和播放规则；显式覆盖才替换。

## 边界

- `panthesia-core/src/song_config.rs` 声明规则、校验身份及解析音轨 / 逐音优先级。共享不可变索引通过 Arc 复制，不随上下文复制整份音符规则。
- `panthesia-engine/src/note_playback.rs` 负责有界读取、版本比较及编辑保存。使用既有后台练习编辑事务；规则与 sidecar、会话替换统一发布。
- 播放事件使用同一个声音策略处理 NoteOn / NoteOff。练习匹配、等音、目标数量、条件摘要与历史恢复使用相同规则。
- 历史条件保留规则；条件摘要区分伴奏或忽略的变化。规则为空时保留旧范围标识，旧成绩继续可读。
- 前端编辑器只呈现一页原始音符。被忽略的音符仍可在列表重新启用；保存后重新取得引擎会话。瀑布使用投影的播放职责显示自动琴键。

入口：演奏页 → 谱面与指法 → 分手与逐音播放 → 逐音播放规则。每页 100 音，服务最多读取 200 音、单次最多编辑 4096 音。

## 保存版本

| 容器 | 有逐音规则时 | 无逐音规则时 |
| --- | --- | --- |
| MIDI 附加文件 | v3 | 按原内容选择 v1 / v2 |
| 练习历史文件 | V2 | V1 |
| 曲目包 | v14，含规则及原 MIDI | 原最低所需版本 |
| 练习备份 | v18，保存历史条件内的规则 | 原最低所需版本 |

曲目包校验规则引用和重复身份，拒绝低版本声明夹带规则。合并导入保留本地同音符规则，替换导入使用来源规则。练习备份保持既有范围：源 MIDI 与 sidecar 通过曲目包迁移。来源 `.synthesia` 原文及未转换换指链仍需后续加入可移植包。
