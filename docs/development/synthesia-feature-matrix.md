开发顺序以 [当前工程计划](modernization-roadmap.md) 为准。本表用于功能覆盖核对；歌曲数据核心、DuET、管理和演奏体验优先。

核对日期：2026-11-19。目标软件为 synthesiagame.com 的钢琴练习软件。范围以以下公开官方资料为基线；后续发现的新官方功能补入本表。官网帮助并未列出全部设置，论坛中的两篇开发日志本次访问失败，不能据此声明已经穷尽所有功能。

## 状态与使用规则

- **已有**：当前代码有明确实现入口；属于实现核对，不能代替设备或完整交付验收。
- **部分**：已有基础，但尚未达到该行验收条件。
- **待做**：本次未找到满足要求的实现，进入开发批次。
- **待核实**：现有证据不足；在对应批次开工时核对实际行为或官方细节。
- **外部依赖**：设备、平台或在线服务影响验收；保留任务，不算完成。

每行按“来源 → 行为 → 实现 → 验收”维护。同一编号中的并列行为必须全部满足才能关闭。下面提到的源码路径相对于仓库；目录位置只用于定位，不能作为完成证据。Pianoteq、原谱管理、转调量化、练习计划与视觉特效仍属产品范围；实现可以替换，资料按明确迁移保护。
