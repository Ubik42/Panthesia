## 固定的主流程

主页 → 选曲 → 歌曲设置 → 观看/左手/右手/双手 → 演奏。返回演奏设置暂停播放；继续同一会话恢复位置。切歌先止音、取消旧的前台等待，后台任务按来源身份继续或取消，旧结果不得覆盖新曲。

手别/颜色/乐器从歌曲设置进入音轨卡片页；只有点“自定义”才打开分手编辑器。顶部齿轮控制显示，缩放控制键盘范围，La 控制音符/琴键标签，手别菜单允许在演奏中即时改练习方式。标签设置区分琴键和音符，支持八度、指法、电脑键位、音名、固定/首调唱名、音级及仅显示自己声部。

全局设置管理输入、输出、音源及扫描目录。音源详细信息留在对应设置对象里。歌曲相关扩展从歌曲设置的二级入口或右键访问；播放舞台不铺设版本栏、任务卡、元数据表格和设备状态面板。

## 用户明确授权的差异

- 使用 Panthesia 品牌和简体中文；图标、字体和素材使用自有或许可明确的实现。
- 速度直接显示并输入 BPM，不把百分比作为主要速度单位。
- 删除“全部歌曲”“入门练习”分类、八秒试听与常驻曲目预览侧栏。
- 文件位置放右键，在资源管理器中显示；自动关联和后台恢复承担日常修复。
- 主线只有连续播放与等待所需琴键；评分、收费解锁和成绩驱动训练不进入主线。
- 皮肤、特效、小节线/拍内细分透明度在显示设置中调整；默认页面与 Synthesia 组织一致。

任何其他默认布局差异须有用户明确指令或可复核的平台必要性，并记录在本节。不能以“现代化”“可发现性”“功能更多”为理由自主添加工作区、侧栏和说明卡。

## 普通选曲的打开行为

2026-11-20 用户明确要求：选择文件时按实际文件存在状态处理，读取当前内容并自动进入歌曲设置。文件缺失只在对应行标记；重新选择其他曲目可直接继续。普通打开使用瞬态导航，不进入持久工作进度、恢复面板或退出保存参与者；后台提交和前端显示同步自动完成。移除曲目打开进度面板及“已保存，界面待更新/打开日志”自动条。原始技术信息写诊断日志，日志入口留在设置中。实现 a6b9960；证据 evidence/direct-song-opening-2026-11-20.json。

## 虚拟双手追加入口（2026-11-21）

演奏页的显示弹出菜单提供“虚拟双手演示”复选项，默认关闭。二级外观设置提供相同开关与不透明度。开启时展示键盘，手部为俯视二维卡通皮肤，覆盖按键但不拦截操作。数据直接来自当前歌曲已保存的手别、指法与有效换指动作，缺失标注不生成弹窗或常驻说明面板。
