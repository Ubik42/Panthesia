# 描述资料的来源默认与个人修改

更新：2026-11-19。对应 C10、C11 的描述字段，以及 C12 的描述资料来源维护。

## 可用行为

- 曲库管理的曲目信息编辑器与演奏页信息窗口共用来源面板。
- 面板逐项显示当前采用值、来源默认值，以及“个人修改 / 随来源更新”状态。
- 勾选个人修改字段后，可一次恢复所选来源默认值；其他字段、指法、分手和谱面关联继续保留。
- 编辑器存在未保存输入、保存结果待核对或冲突时，先处理当前输入，再执行恢复。
- 演奏页曲名下显示副标题、作曲家与改编者；演奏者、版权及许可放在“署名与许可”中。
- 窄窗口保留信息按钮，菜单“曲库 → 当前曲目信息”也可进入。
- 批量模板覆盖 11 个资料字段，支持曲名、副标题、作曲家、改编者、演奏者、版权、许可说明、作品集、难度、标签及备注；沿用逐首预览、冲突保护和保存流程。

## 数据规则

`MetadataLayers` 保存来源格式、来源文件内容标识、完整默认资料和个人覆盖字段集合。有效资料仍由 `SongMetadata` 提供给现有搜索、排序与练习流程。

首次导入时，已有非空资料按个人修改保留。后续编辑只把实际修改的字段标为个人覆盖。清空文本或标签也是有效个人选择，重导入时继续保留。再次导入更新来源默认值，并重新计算未覆盖字段。勾选导入替换选项时，仅来源非空描述字段解除个人覆盖。

恢复操作同时核对曲目内容、当前有效资料和来源 / 覆盖快照。来源变化但有效值相同也会产生冲突。读取与校验使用同一份附加资料快照。写入复用既有编辑事务、目录锁和依赖核对。

资料历史继续记录有效字段变化；恢复旧字段值会成为新的个人修改。历史未提供旧来源文件及旧覆盖集合的整体回滚。原始来源文件独立保存在 metadata-sources 中，尚未随分享包分发。

## 模块与格式

- 核心合成规则：`panthesia-core/src/metadata_layers.rs`。
- 来源快照与恢复服务：`panthesia-engine/src/metadata_defaults.rs`。
- 界面读取与回执校验：`features/library/metadataClient.ts`。
- 共用来源面板：`features/library/MetadataDefaultsPanel.tsx`。
- 演奏页展示：`features/practice/SongCredits.tsx`；按曲目或编辑结果读取，播放时不轮询资料。
- 含来源分层的 MIDI 附加资料使用 v4，曲目包使用 v15。
- 模板注册表根据字段使用 v1 / v2；练习备份含扩展模板时使用 v19。旧文件仍可读；版本不足时明确拒绝含新字段的记录。
