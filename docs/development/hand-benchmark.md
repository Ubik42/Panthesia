# 虚拟手 benchmark

用舞台同一份代码（`virtualHandPlan.ts`、`virtualHandPose.ts`）按 60 帧/秒逐帧演奏若干首歌，统计准确、解剖、平滑三类指标。每次改手部算法前后都跑一次，结果写进 `progress.md`。

## 运行

```powershell
cd panthesia-web
node scripts/hand-bench.mjs                       # 当前代码
node scripts/hand-bench.mjs --baseline HEAD       # 与某个提交对比（逐项给出变化与优劣）
node scripts/hand-bench.mjs --songs "花 - 藤井风" --seconds 240 --out ..\work\hand-bench\report.json
node scripts/hand-bench.mjs --refresh             # 指法算法改动后重新导出歌曲
```

- 语料：默认 6 首 B 站转录曲（`D:\Music\MIDI\B站纯钢琴演奏视频转MIDI`），每首前 90 秒。脚本只把清单与 MIDI 复制到 `work/hand-bench/songs`，在副本上打开，语料本身只读。
- 导出：经浏览器调试服务（`127.0.0.1:32124`）打开副本，取分手、指法、换指与踏板区间，缓存为 `work/hand-bench/cache/<歌名>.json`。服务未运行时脚本用 `target/debug/panthesia-service.exe` 启动，数据目录为 `work/hand-bench/data`；先 `cargo build -p panthesia-engine --bin panthesia-service`。
- 键盘：1 像素 = 1 毫米，白键宽 23.5、黑键宽 13.7、键长 150。
- 排查：`HAND_BENCH_DEBUG=1` 输出手腕突变时刻与关节突变按关节的分布；`HAND_BENCH_TRACE=<秒>` 输出该时刻前后 0.13 秒每帧的手腕位置、转角与按键状态。

## 指标

| 类别 | 指标 | 定义 | 方向 |
|---|---|---|---|
| 准确 | 击键命中 % | 每个音在开始后 min(40 ms, 时值/2) 那一帧：该手指处于按下状态，且指尖在键宽内（±2 mm）、高出键面不超过 3 mm | 高 |
| 准确 | 保持覆盖 % | 在“必须按住”的时段（按下到原松键或被踏板接住的时刻，见 `Contact.free`）中手指处于按下状态的帧比例 | 高 |
| 解剖 | 手指交叉 ‰ | 手掌坐标中相邻指尖顺序颠倒超过 1 mm 的帧（拇指穿越时不计拇指） | 低 |
| 解剖 | 拇指反折 ‰ | 拇指近节高于掌骨线或末节高于近节超过 10° 的帧 | 低 |
| 解剖 | 空闲手指上翘 ‰ | 不按键的手指：指尖高过指根、伸过琴键 98% 长度，或近节上抬超过 8° | 低 |
| 解剖 | 按键手指蜷缩 ‰ | 按键手指指尖到指根的水平距离小于手指长度一半 | 低 |
| 平滑 | 手腕速度 p99、加速度 p99、急动度均值 | 手腕位置逐帧差分 | 低 |
| 平滑 | 手腕突变 ‰ | 手腕加速度超过 20 m/s² 的帧，对应“整手跳变” | 低 |
| 平滑 | 手掌转速 p99 | 手掌转角逐帧差分 | 低 |
| 平滑 | 空闲指尖加速度均值、空闲指尖突变 ‰ | 连续三帧都不按键的指尖；突变阈值 60 m/s² | 低 |
| 平滑 | 关节角速度 p99、角加速度均值、关节突变 ‰ | 每指 4 个角：指根侧摆、指根抬起、近节关节、远节关节；拇指为掌骨转向、掌骨抬起、MCP、IP。只计连续三帧不按键的手指；突变阈值 20 rad/s | 低 |
| 成本 | 每帧耗时 ms | 单手一帧 `handPose` 的平均耗时 | 低 |

## 调参记录

- 手腕平滑周期 `WRIST_PERIOD`：0.3 / 0.5 / 0.8 / 1.2 s → 手腕突变 11.2 / 3.5 / 1.1 / 0.5 ‰，击键 96.9 / 96.3 / 95.7 / 93.0 %，取 0.8。
- 可达修正权重：按“原始放置偏离”重新加权（迭代加权）会把原始放置的跳动带回来，全面变差，弃用；改为在平滑路径上逐帧检查可达，把修正量再做同样的平滑后叠加。修正权重 400 / 150 / 50 / 15 / 5 → 手腕突变 5.1 / 3.7 / 2.7 / 2.0 / 1.9 ‰，击键不变；够不到键时的权重 `REACH_FIRM` 40 / 150 → 击键 96.2 / 96.3 %，手腕突变 3.0 / 4.2 ‰，取 40。
- 拇指连续性：限制掌骨转速会让拇指停在反折姿态（反折 30 → 45–64 ‰），弃用；只保留与上一帧的偏离惩罚，0.12·Δ度 + 8·Δ下倾 / 0.3 + 20 / 0.6 + 40 / 1.2 + 80 → 关节突变 19.2 / 18.7 / 16.7 / 15.8 ‰，最后一档击键降到 94.6 %，取 0.6 + 40。
- 手的缩放 `HAND_SCALE`：1 / 0.94 / 0.92 / 0.9 → 击键 96.8 / 96.2 / 95.0 / 93.8 %，蜷缩 41 / 58 / 70 / 81 ‰；手腕高度随缩放降低会使拇指反折翻倍，保持 40 mm。取 0.94。
- 放松伸展权重 `RELAX` 0.6 → 1.0：蜷缩 57.7 → 54.7 ‰，击键 96.2 → 94.8 %，保持 0.6。
