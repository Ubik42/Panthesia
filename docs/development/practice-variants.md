# 同曲单一原始 MIDI 与练习版本规范

日期：2026-11-18。适用于本机 Panthesia 的转调、量化、练习记录与导出。

## 曲目如何保存

同一份演奏通常保存一份原始 MIDI。文件的内容校验值作为身份；移动、重命名继续沿用身份。软件按身份保存转调半音、量化密度、是否量化时值和手动调性。原始文件始终保留原音高、原时序与原始演奏事件。

不再为了原调、C 调、十六分量化分别生成长期维护的 MIDI。旧文件继续保留，用户确认内容关系后再整理。人工改音、删掉声部、重新编配双手或不同转录模型的结果属于不同演奏，可以独立保留。原始录音与可靠的原始谱也应独立保留。

## 转调

- 范围为上下 24 个半音，提供单半音、八度与“移到 C”按钮。
- 调性优先使用手动设置，再使用 MIDI 调号，最后提供可修改的估计。估计只是音级分布启发式，不代表人工调性分析。
- “移到 C”保留大调或小调性质。C 小调不能通过半音平移变成 C 大调。
- 移到 C 时优先选择仍在 88 键范围内的八度等价移调，再选距离最短的半音数。
- 鼓通道保持音高。超出 MIDI 0–127 拒绝操作；超出实体钢琴 21–108 显示提示，瀑布仍扩展展示目标音域。
- 实体键盘按新音高练习，等待判断也要求新音高。

## 量化

- 提供原始时序、1/8、1/16、1/32。以每个实际小节的起点为基准，将起音吸附到最近网格。
- 默认同时量化时值，最短保留一个所选网格。关闭“同时量化时值”后只移动起音，保留原音符门长。
- 速度变化、控制器与踏板的原始时序保留。量化后的踏板与起音关系可能略有变化，按听感选择原始演奏或更细网格。
- 同一音轨、通道和音高的两个起音若落到同一格，拒绝该密度并提示选更细网格。当前版本不自动合并或删除连续同音。
- 普通二分细分适用于这版练习量化。三连音、摇摆与复杂混合节奏应保留原时序；本版没有自动推断这些节奏。
- 切换量化成功后，瀑布网格密度同步到该量化密度；线条透明度保留用户设置。

## 运行时与历史

原始 MIDI 只解码一次作为源缓存，练习版本由其派生。音符、发声事件、等待判断、时间线和 MIDI 五线谱使用同一份有效演奏。重复切换始终从源缓存计算，避免累积移调与量化误差。

更改有效演奏会先保存已有的已评分本轮，再暂停、停止旧声音、重建目标并清除旧选段。设置按曲目保存，重新打开会恢复。手动修正调性标记不改变有效音符。

历史条件的网格签名包含 `practice-v1:半音,量化,时值开关`，评分目标范围也包含有效音符。不同版本不会归为同条件成绩。恢复历史条件时从签名恢复对应变换；历史批阅的参考音按相同变换准备。已有网格或分手改变时沿用原有的条件校验提示。

原始 MusicXML/PDF 保留原调与原版布局。启用练习变换时直接显示有效 MIDI 的五线谱；恢复原始演奏后可继续查看关联原谱。源谱的指法、分手与小节修正需要恢复原始演奏后编辑，避免把练习版位置写回源谱。

录音、活动计划、速度阶梯与完整演奏期间须先结束当前项目，再更改有效演奏。原始作品关系和旧文件不自动删除。

## 导出

“文件 → 导出原始 MIDI”复制源 MIDI；“导出练习版 MIDI”生成当前转调、量化后的音符与事件，保留速度、拍号、控制器、踏板和适用的移调调号。时序精度按 MIDI tick 表达。

练习版导出用于其他软件和分享。它不会自动加入曲库，也不会替换原文件。文件名包含转调数和量化密度。个人指法、原始谱与完整个人历史不编码进这个 MIDI。

练习设置目前按本机曲目身份保存。跨软件使用练习版 MIDI；迁移本机当前变换设置时，应随个人资料保留 `web-preferences.json`。现有练习资料备份和单曲包尚未单独收录当前变换参数；历史记录中的变换签名可用于恢复对应那次练习。
